# 나한테 어울리는 군산시 부서는?

군산시 새내기 공무원을 위한 **업무 성향 기반 부서 추천 재미용 테스트**입니다. 실제 인사배치나 직렬과는 무관합니다.

## 특징

- 전자문서함, 자료요구, 주간업무, 행정문서, 보조금 정산, 현장점검 등 공직생활 공감형 질문
- 테스트 완료 후 전자문서함에 도착한 `정기인사 알림` 공문을 열어 결과를 확인하는 흐름
- 모바일 9:16 및 PC 16:9 환경에 대응하는 반응형 공공문서풍 UI
- 질문·답변·부서 추천 데이터가 `data.js`에 분리된 순수 Vanilla HTML/CSS/JS 프로젝트

## 로컬 실행

별도 빌드 과정 없이 정적 파일 서버로 실행할 수 있습니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## GitHub Pages 배포

저장소의 **Settings → Pages**에서 배포 소스를 현재 브랜치의 루트(`/`)로 지정하면 됩니다.

## 파일 구조

- `index.html`: 화면 구조
- `style.css`: 반응형 디자인과 애니메이션
- `app.js`: 테스트 진행 및 결과 계산 로직
- `data.js`: 질문, 답변 점수, 추천 부서 데이터
