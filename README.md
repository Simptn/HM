# 나한테 어울리는 군산시 부서는?

군산시 신규공무원을 위한 **업무 성향 기반 부서 추천 재미용 테스트**의 기본 UI 프로토타입입니다. 실제 인사배치나 직렬과는 무관합니다.

## 현재 구현 범위

- 신규공무원 성향검토 기안문 형태의 시작 화면
- 문서작성 상태바, 타이핑 질문, 검토완료 도장이 포함된 15문항 질문 화면
- 5문항 단위 중간 검토 진행률 화면
- 테스트 완료 후 `정기인사 알림`이 도착하는 전자문서 수신목록
- 열람 처리, 접수 도장, 공문 펼침 애니메이션
- 모바일 9:16 및 PC 16:9 중앙 고정형 반응형 레이아웃
- 공유 영역과 조작 버튼이 분리된 결과 공문 및 PNG 이미지 저장
- `prefers-reduced-motion` 사용자용 모션 최소화

질문과 결과 데이터는 현재 레이아웃 검토용 임시 데이터이며 `data.js`에서 관리합니다.

## 로컬 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## GitHub Pages 배포

저장소의 **Settings → Pages**에서 배포 소스를 현재 브랜치의 루트(`/`)로 지정합니다.
